## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_references.Main
java -cp build part2_library.Main
```

## Что показать на защите

Сначала покажи, как две ссылки меняют один Box. Затем отличие изменения поля от переназначения параметра. В библиотеке добавь книги, отсортируй и найди по названию и году.

## Как объяснить

Java передаёт всё по значению. Для объекта передаётся копия значения ссылки. Через неё можно изменить общий объект, но присваивание параметру new Box не меняет переменную вызывающей стороны. BookLibrary хранит массив объектов и отдельный count, а методы скрывают детали хранения.

## Возможные вопросы

- **Передача объектов — по ссылке?** Точно: по значению ссылки, не pass-by-reference переменной.
- **Что сортируется: книги или копии книг?** Меняются ссылки внутри массива; сами объекты не копируются.
- **Почему нельзя обходить весь массив из 100 элементов?** После count находятся неиспользованные null-слоты.
